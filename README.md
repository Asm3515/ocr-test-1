===========================================================
                AI Invoice Processing Tool
===========================================================

This is a proof-of-concept (POC) AI-powered invoice processing tool.
It allows users to upload invoices, extract text via OCR, 
and query them using natural language or voice.

Built with:
- Next.js
- Node.js
- MongoDB
- Deployed on Vercel

-----------------------------------------------------------
Getting Started
-----------------------------------------------------------

Run the development server:

    npm run dev
    # or
    yarn dev
    # or
    pnpm dev
    # or
    bun dev

Open http://localhost:3000 in your browser.

Edit the page by modifying app/page.tsx. 
The page auto-updates as you edit the file.

-----------------------------------------------------------
Project Structure
-----------------------------------------------------------

Frontend   : Next.js + TailwindCSS
Backend    : Node.js + Express routes
Database   : MongoDB (JSON + Vector Search)
Deployment : Vercel
APIs       : Swagger (OCR, Upload, CRUD, Summarization)
